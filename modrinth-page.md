# Shulker Restorer - Modrinth page copy

## description

Brings back selected older shulker and shulker bullet behavior for farms.

## body

Shulker Restorer brings selected shulker mechanics from Minecraft 1.20.5 to newer versions of the game.

It restores older bullet collision and deflection behavior, along with the earlier teleport restrictions. It is intended for farm designs that depend on those mechanics.

### Installation

Install it on your Fabric server, or in your own game for singleplayer. Players joining a server do not need it on their clients. Fabric API is not required.

Farm results still depend on the design and the rest of the game. This mod does not guarantee a particular production rate or restore every older mechanic.
